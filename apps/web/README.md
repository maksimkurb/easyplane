# EasyPlane web panel

React 19 + Vite + Tailwind 4 + shadcn/ui on Base UI (`base-nova`), TanStack
Query, i18next (en/ru), lucide-react. The API client is generated by orval from
the server's OpenAPI document.

```bash
bun install            # from the repo root
bun run --cwd apps/web dev
bun run --cwd apps/web build
bun run --cwd apps/web typecheck
bun run --cwd apps/web lint
bun run --cwd apps/web test

# Regenerate the client after changing server routes
bun run openapi:generate
bun run --cwd apps/web api:generate
```

In development Vite proxies `/api` and `/health` to `http://127.0.0.1:8080`
(override with `EASYPLANE_API_URL`). In production the Fastify server serves
`apps/web/dist` and the SPA fallback.

Authentication is cookie based: the HttpOnly `easyplane_session` cookie is sent
automatically, and mutating requests add `x-csrf-token` from the readable
`easyplane_csrf` cookie (`src/api/client.ts`).

UI conventions (components, theme/language providers, sidebar, table and form
primitives) are copied from the reference `keenetic-pbr-go/frontend` project so
the two panels stay visually consistent; no code is linked across repositories.
