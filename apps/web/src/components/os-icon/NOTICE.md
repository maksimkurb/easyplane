# OS glyph assets

`os-icons.ts` vendors SVG path data from [Simple Icons](https://simpleicons.org)
release 16.38.1, which is released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). The
paths are copied instead of imported from the `simple-icons` npm package so the
web bundle only carries the glyphs the panel uses.

The Windows glyph is drawn locally for this project, because Simple Icons no
longer distributes Microsoft marks.

Operating-system names and logos are trademarks of their respective owners.
They appear here only to identify the operating system a device reports, not to
imply endorsement or affiliation.
